# Nadila Pilar Kencana - Portfolio

A modern, responsive portfolio website built with React.js and Tailwind CSS.

## Features

- Modern dark theme design
- Responsive layout for all devices
- Smooth scrolling navigation
- Interactive hover effects
- Professional sections: About, Experience, Projects, Skills, Certifications, Contact

## Tech Stack

- React.js
- Vite (build tool)
- Tailwind CSS
- HTML5 & CSS3

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Customization

To customize the portfolio with your own information, edit the `portfolioData` object in `src/App.jsx`.

## Deployment

This project can be deployed to any static hosting service like Vercel, Netlify, or GitHub Pages.
